Morecome (몰컴)

열려 있는 창 하나를 화면 왼쪽 아래에 작게 띄워 보는 프로그램입니다. 작은 화면 안에서 클릭하고 타이핑하면 원본 창에 그대로 전달되고, 원본 창은 앞으로 튀어나오지 않습니다.

시작하기

설치가 필요 없습니다. Windows 10·11이면 exe 파일 하나로 실행됩니다.

실행

Morecome.exe를 더블클릭합니다. 화면 왼쪽 아래에 빈 미니 창이 뜹니다.

창 고르기

미니 창을 우클릭 → 창 선택 → 보고 싶은 창을 고릅니다.

바로 사용

미니 창 안을 클릭하고 타이핑하면 원본 창에 전달됩니다. 원본은 다른 창 뒤에 있어도 됩니다.

화면 미리보기

실제 앱과 같은 색과 비율로 그렸습니다. 오른쪽 설정을 바꾸거나 미니 창 위에 마우스를 올려 보세요.

설정 바꿔 보기

240 / 360 / 480 px. 높이는 원본 비율에 맞춰 자동.

미니 창을 끌어 옮기고, 네 모서리의 주황 손잡이 중 아무거나 끌어 크기를 바꿔 보세요.

불투명도

평소 5%로 거의 안 보입니다. 미니 창 위에 마우스를 올리고 1초 머물면 80%로 서서히 밝아집니다. 지연 시간과 두 불투명도는 메뉴에서 바꿀 수 있습니다.

키보드로 스크롤하기

휠이 안 먹는 곳에서 씁니다. 썸네일을 한 번 클릭한 뒤 아래 키를 누르세요.

↓ ↑조금씩 내리기 / 올리기
Page Down Page Up한 화면씩 내리기 / 올리기
Space Shift+Space웹페이지에서 한 화면씩 내리기 / 올리기
Home End맨 위 / 맨 아래

유튜브 영상에 초점이 있으면 Space는 일시정지, ← →는 5초 이동, ↑ ↓는 볼륨입니다. 페이지를 내리려면 영상 바깥(댓글 쪽)을 먼저 클릭하세요.

클릭 방식 두 가지

우클릭 → 클릭 방식에서 고릅니다. 기본은 "조용히"입니다.

원본 창 안 띄우고 전달 기본

원본 창에 입력 신호만 보냅니다. 원본은 제자리에 가만히 있습니다.

  • 작업 중인 창이 바뀌지 않습니다.
  • 드래그와 타이핑도 전달됩니다.
  • 게임, 일부 스토어 앱, 관리자 권한 앱은 무시할 수 있습니다.
  • Ctrl·Shift 조합키는 안 통할 수 있습니다.

원본 창 앞으로 가져와서 클릭

원본 창을 앞으로 꺼내고 마우스를 실제로 움직여 클릭합니다.

  • 거의 모든 프로그램에서 확실히 됩니다.
  • 크롬이 가려져 있어도 휠이 먹습니다.
  • 클릭할 때마다 원본 창이 앞으로 나옵니다.
  • "클릭 후 마우스 커서 되돌리기"를 켜면 커서는 원래 자리로 돌아옵니다.

조용한 방식이 안 먹는 프로그램이면 두 번째 방식으로 바꾸세요.

알아 둘 제한

Windows나 다른 프로그램의 동작 때문에 생기는 제한입니다.

▁
원본 창을 최소화하면 안 보입니다

Windows는 최소화된 창의 화면을 그리지 않습니다. 최소화 대신 다른 창 뒤에 두세요.

▶
크롬 동영상이 멈춰 보일 수 있습니다

크롬은 최대화된 채 완전히 가려지면 화면 그리기를 멈춥니다. 기본으로 켜진 선택한 창 최대화 풀기가 이를 막아 줍니다. 그래도 멈추면 아래 문제 해결을 보세요.

⇕
크롬이 가려져 있으면 휠이 안 먹습니다

크롬은 다른 창 위에서 굴린 휠을 무시합니다. 키보드로 스크롤하거나 "앞으로 가져와서 클릭" 방식을 쓰세요.

🛡
관리자 권한 프로그램에는 입력이 안 갑니다

Windows 보안 정책입니다. 그런 프로그램을 쓰려면 Morecome도 관리자 권한으로 실행하세요.

문제 해결

자주 겪는 상황과 해결 방법입니다.

미니 창이 검은 화면만 보여요
원본 창이 최소화되어 있는지 확인하세요. 작업 표시줄에서 원본을 한 번 열어 둔 뒤 다른 창 뒤로 보내면 다시 보입니다.
크롬 유튜브가 가려지면 멈춰요

순서대로 시도하세요.

  1. 우클릭 메뉴의 선택한 창 최대화 풀기가 켜져 있는지 확인하고, 창을 다시 선택합니다.
  2. 크롬 창이 화면에 한 귀퉁이라도 보이게 둡니다. 두 번째 모니터에 두는 것도 방법입니다.
  3. 크롬 주소창에 chrome://flags를 열고 "Calculate window occlusion on Windows"를 Disabled로 바꾼 뒤 재시작합니다.
  4. 유튜브 영상에서 우클릭을 두 번 해 화면 속 화면을 켜고, 그 작은 창을 Morecome으로 봅니다.
클릭해도 원본이 반응하지 않아요
우클릭 → 클릭 방식 → 원본 창 앞으로 가져와서 클릭으로 바꿔 보세요. 그래도 안 되면 원본이 관리자 권한으로 실행 중인지 확인하세요.
크기 조절 모드에서 클릭이 안 돼요
조절 모드(주황 테두리)에서는 클릭이 원본으로 가지 않습니다. 조절이 끝나면 우클릭 → 크기 → 드래그로 크기·위치 조절의 체크를 풀어 주세요.
설정은 어디에 저장되나요?

항상 위, 크기, 위치, 불투명도, Boss Nearby와 그 지연·불투명도, 최대화 풀기, 클릭 방식, 마지막으로 본 창이 저장됩니다. 다음에 실행하면 같은 제목의 창이 열려 있을 때 자동으로 다시 연결합니다.

%APPDATA%\Morecome\settings.txt
개발자 참고: 빌드와 동작 원리
  • 빌드는 폴더의 build.cmd를 실행합니다. Windows에 내장된 C# 컴파일러를 쓰므로 Visual Studio가 필요 없습니다. 같은 폴더에 notepad.ico가 있으면 아이콘으로 묶고, 없으면 기본 아이콘으로 빌드합니다.
  • 썸네일은 Windows의 DWM 썸네일 기능으로 그립니다. 화면 캡처가 아니라서 CPU를 거의 쓰지 않습니다.
  • 조용한 방식은 원본 창 안의 해당 지점에 마우스·키보드 메시지를 보냅니다.
  • 작업 표시줄에는 메모장 아이콘과 "제목 없음 - 메모장" 제목으로 표시됩니다.
  • %APPDATA%\Morecome\debug.on 파일을 만들어 두면 전달 좌표가 debug.log에 기록됩니다.
